# fieldnotes

Field-service engineering notebook for the Redpine and Boreal device programmes.

* `reviews/<project>/` holds the annotated source listings produced for each
  firmware review, one section per unique listing.
* Review threads live in the issue tracker. Each review issue records the
  release-gate decision for the build it covers.

This repository is the team's canonical notebook. Historical, frozen copies are
kept in the separate `fieldnotes-archive` repository; that archive is read-only
and must not be updated.
